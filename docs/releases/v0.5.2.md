# Focus Island v0.5.2 — Jira setup, assignment sync, and a new app icon

- **Jira in Setup:** Settings → Setup → Jira authorization now contains the connection controls. Authorize Jira opens the installed Atlassian CLI in Terminal for browser sign-in; finish that flow, then connect. Already signed-in users can connect directly.
- **Sync my Jira tasks:** available in Setup and the board’s Jira menu. Import all assigned, unfinished issues into Backlog and refresh existing linked cards. Repeated syncs reuse cards; local notes, columns, sessions, and timers are preserved. Selected imports remain available through Add from Jira.
- **New app icon:** Dock, Finder, and About use the supplied `Assets/Brand/icon.png`, converted into the macOS icon sizes with its proportions and transparency preserved.
- **Jira command cleanup:** prevent an operation from hanging after its CLI process exits.

Sync fetches new issue details before inserting the batch. Cancellation, detail-fetch failures, and detach/delete during a pending sync have regression coverage. Jira data access is read-only.

Validation: 922 tests reported across 88 suites passed, including live import and repeated assignment sync against a disposable board; only the optional localized settings preview was skipped. All 986 localization keys passed. Setup, connection, import, and task rendering checks passed, and the Setup screens and generated icon were visually inspected. Standards and specification reviews found no remaining issues. The user's real board was not modified.

Download the universal `Focus.Island.dmg` or `Focus.Island.zip` for macOS 14 or later on Apple Silicon or Intel. The build is ad-hoc signed and not Apple-notarized. Atlassian CLI is installed separately; supported paths are `/opt/homebrew/bin/acli`, `/usr/local/bin/acli`, and `~/.local/bin/acli`.

Jira remains an opt-in preview for one Jira Cloud account/site at a time. See the [implementation and validation record](../JIRA-INTEGRATION-PLAN.md).
