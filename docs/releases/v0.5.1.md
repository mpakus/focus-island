# Focus Island v0.5.1 — Fix Jira discovery and verify live import

Fixes Jira connection and discovery failing with ACLI 1.3.39 because v0.5.0 requested unsupported search fields. Search now requests the fields ACLI accepts; selected issue details supply the project, description, and update timestamp before import or refresh. Incomplete detail responses still cannot change local data.

Live verification passed against one Jira Cloud account: authentication, assigned-issue discovery, detail retrieval, and importing/refreshing one issue in a disposable board. Local notes and completion were preserved, and Jira status stayed unchanged. No Jira writes were made.

The regression test failed before the fix and passed afterward. It covers the real search response shape and rejects incomplete snapshots before import or refresh. The full suite passed with 916 tests reported across 88 suites, including the live check; only the optional localized settings preview was skipped. All 982 localization keys passed validation. Standards and specification reviews found no remaining issues in this patch.

Download `Focus.Island.dmg` or `Focus.Island.zip` for macOS 14 or later, on Apple Silicon or Intel. The build uses ad-hoc signing and is not Apple-notarized. Atlassian CLI must be installed separately and signed in with `acli jira auth login --web`; connect through Settings → Focus → Jira.

Jira remains an opt-in preview. Live verification covers one account and a small result set; large-volume pagination, other tenant policies, and future CLI versions are not yet verified. See the [implementation and validation record](../JIRA-INTEGRATION-PLAN.md).
