# Focus Island v0.2.0 — Your first task and clearer session statuses

Onboarding takes you straight to a task in progress, sessions have readable status labels, and the island stays quiet when you can already see the session's reply.

## Installation and updates

1. Download `Focus.Island.dmg` below — one file for Apple Silicon and Intel.
2. Open the DMG and drag **Focus Island** into Applications. When updating, replace the previous version.
3. On first launch, right-click the app → Open.
4. Click "Connect" in the island below the notch to install the Claude Code hooks.

> [!NOTE]
> The build is signed with a local certificate and is not notarized by Apple, so macOS asks you to confirm the first launch. If "Open" does not appear, use System Settings → Privacy & Security → Open Anyway.

## What's new

- **Your first task:** a three-step onboarding flow. The island suggests a task based on running Claude sessions, picks up those sessions and their project directory, moves the task to "In progress", and starts focus with one button. If Claude is not running yet, the first new session joins the task automatically.
- **Session statuses:** every session has a badge — "Working", "Waiting for a reply", or "Your turn". Use the circle on the left to mark a session as done; completed sessions appear in the "Done" group. Sessions waiting for permission have a "Respond" button.
- **Quiet when the reply is visible:** if the session is open in Claude.app or a terminal, its completion summary does not pop up and the island stays closed. The reply is marked as read immediately.

## Fixes

- **Claude.app sessions keep their task binding** when Claude.app restarts a session with a new ID.
- **No duplicate sessions** after restarting Focus Island.
