# Focus Island v0.7.0 — ClickUp tasks and Codex usage

Connect ClickUp from Setup with browser authorization, then sync assigned unfinished tasks into the board. Selected imports, source links/status, manual refresh, reconnect, forget, and detach preserve local columns, notes, sessions, timers, and history. No CLI or personal token is required. Jira integration remains available alongside ClickUp.

Codex account usage now appears beside Claude in the open island. It reads the signed-in official CLI or bundled desktop CLI, refreshes every two minutes, and labels quota windows by their actual duration. Setup includes status and manual refresh; no additional bridge is required.

The README includes two new screenshots with synthetic data and updated setup instructions. English, Spanish, and Russian interfaces include the new controls.

Validation includes browser/transport fixtures, migration and preservation checks, coordinator and process-cleanup tests, rendered UI checks, live Codex quotas, and private recorded ClickUp responses imported repeatedly into a disposable board. ClickUp’s native browser proof read 93 assigned tasks from one Workspace. Live multi-page and multi-List permission scenarios, and the packaged ClickUp sign-in flow, are not certified yet.

ClickUp read budgets apply; sync is manual and an expired sign-in requires reconnection. Database v8 creates a consistent backup before migration. Releases use ad-hoc Apple signing and signed Sparkle updates; they are not notarized by Apple.
