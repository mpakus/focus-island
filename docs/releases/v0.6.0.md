# Focus Island v0.6.0 — Browser Jira sign-in and app updates

- **Integrate Jira** opens your browser for read/search authorization and returns to the app. No CLI installation or copied commands are needed. Credentials stay in macOS Keychain.
- **Settings → About** checks GitHub Releases and offers signed updates through Sparkle, including download, installation, and relaunch. Background checks can be disabled there.
- About credits Renat "MpaK" Ibragimov ([aomega.co](https://aomega.co)), Dias Zhanabayev, and Octane0411, with **Made in Austin ☆ Texas**.
- Assigned-issue sync continues to preserve local progress, notes, sessions, and timers. The app only reads Jira.

Install this release manually once from v0.5.x; later releases can update in the app. Existing Jira cards remain, but Jira requires a new browser authorization. Your organization must permit Atlassian MCP access.

The DMG and ZIP contain the same universal macOS 14+ app for Apple Silicon and Intel. The app is ad-hoc signed and is not Apple-notarized; Sparkle separately verifies the signed feed and update archive.

Validation: 931 tests across 89 suites, localization checks for all three languages, rendered Setup/About checks, and a universal package smoke test. Browser consent, signed-feed verification, and installation acceptance remain pending until release preparation completes.
