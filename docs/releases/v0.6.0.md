# Focus Island v0.6.0 — Jira reconnect, app updates, and a refreshed icon

- Connect your already signed-in **Atlassian CLI** account from Settings → Setup, then choose **Sync my Jira tasks** to import assigned, unfinished issues into Backlog. Repeat syncs preserve local progress, notes, sessions, and timers. The app only reads Jira.
- **Reconnect Jira** retries your selected connection. **Forget Jira** clears Focus Island’s connection and browser credentials while keeping cards and history; the shared CLI account stays signed in. Both actions are available in Setup and the board’s Jira menu.
- Fixed a crash during CLI site lookup. Setup also explains Homebrew’s formula-specific trust command when installation is blocked.
- The app and Dock icon now have a dark blue background.
- **Settings → About** checks GitHub Releases and offers signed updates through Sparkle. Background checks can be disabled there.
- About credits Renat "MpaK" Ibragimov ([aomega.co](https://aomega.co)), Dias Zhanabayev, and Octane0411, with **Made in Austin ☆ Texas**.

**Browser sign-in preview:** Integrate Jira opens Atlassian’s read/search authorization page. Consent currently returns `invalid_request` for the verified account before returning to the app. If this happens, cancel and use the signed-in CLI option. Browser sign-in has automated coverage but has not completed a live import.

Install this release manually once from v0.5.x; later releases can update in the app. Connect once after upgrading; existing Jira cards and history remain.

The DMG and ZIP contain the same universal macOS 14+ app for Apple Silicon and Intel. The app is ad-hoc signed and is not Apple-notarized; Sparkle separately verifies the signed feed and update archive.

Validation: 933 tests across 89 suites, 1007 localization keys in English/Spanish/Russian, rendered Setup/About checks, and live CLI sync on a disposable board. Official Sparkle signature verification and disposable-app version checks passed, including rejection of a tampered feed. Update installation/relaunch remains unverified.
