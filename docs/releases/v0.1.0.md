# Focus Island v0.1.0 — First release

The first release of Focus Island, a macOS notch companion for Claude Code sessions. The island keeps one task, its sessions, and a timer in focus, with everything else out of the way.

## Installation

```bash
gh release download v0.1.0 -R dias-zhanabayev/focus-island -p install.sh -O - | zsh
```

Or install manually: download `Focus.Island.dmg`, drag **Focus Island** into Applications, then right-click the app → Open on first launch. The build is signed with a local certificate and is not notarized by Apple.

## Features

- **Focus:** one task in focus, its sessions, a "Waiting outside task" section, a task board, and a daily summary.
- **Timer:** 50 minutes of focus and a 10-minute break by default, with 25/50/90-minute or custom focus intervals. A sound plays and the break starts automatically after five seconds.
- **Task sessions:** select multiple sessions, mark a session that has finished its work as "✓ Done", or move and unbind sessions from the "⋯" menu.
- **Claude.app:** "Open" takes you to the correct session; session names and turn summaries come from Claude.
- **Quiet behavior:** a new session does not open the island. When Claude finishes, the island shows a one-line summary instead of the full reply.

Requires macOS 14 or later. Universal build for Apple Silicon and Intel.
