# Focus Island v0.8.0 — Command palette, review handoff, and local backups

Move between tasks, agent sessions, and focus actions with the new command palette. Press **⌥⌘K** from anywhere, or **⌘K** while Focus Island is active, to search tasks and sessions, capture a new task, open completed work for review, or start, pause, and resume the timer. The board toolbar and app menu also open the palette; its global shortcut can be disabled in Settings.

**Review changes** brings the agent's completion summary, task criteria, branch/worktree, and browsable file diffs into one window. It includes staged, unstaged, deleted, and untracked files. The review shows the current worktree relative to `HEAD`; it does not attribute shared changes to one agent or include already committed work. Large previews are explicitly bounded.

**What's next?** considers the task in focus and how long sessions have been waiting. Approvals and questions share the same ranking. Sessions in the current task come first until another session exceeds the waiting-reminder threshold, when the longest wait takes priority. Each suggestion explains why it appears, and repeated session events no longer reset the observed wait.

**Backups and restore** adds daily local snapshots, manual backups, export, and a validated restore preview in Settings → Focus. Seven daily copies are retained; manual and recovery copies remain until removed. Restore freezes the selected backup, quits the app, and applies it on the next launch after saving a recovery copy of the current database. Snapshots include tasks, notes, criteria, session history, prompts, activity, day plans, and timers. Preferences and sign-in credentials are excluded, and Jira and ClickUp are not changed.

All new controls are available in English, Spanish, and Russian. No new dependency or database schema migration is required. Verification covers keyboard command routing, recommendation ordering, real temporary Git repositories, rendered UI, backup retention, older-schema validation, rejected restores, and portable SQLite WAL backups with recovery checks.

Requires macOS 14 or later. The DMG and ZIP contain a universal Apple Silicon/Intel app. Releases use ad-hoc Apple code signing and signed Sparkle updates; they are not notarized by Apple. Existing Jira, ClickUp, and Codex preview/support limits remain as documented in the README.
