# Focus Island v0.4.0 — Codex и три языка интерфейса

Нативное приложение для macOS 14+ с поддержкой Claude Code, предварительной интеграцией Codex и интерфейсом на английском, испанском и русском языках.

## Установка и обновление

1. Скачайте `Focus.Island.dmg` или `Focus.Island.zip` ниже. Оба архива содержат одно универсальное приложение с нативными бинарными файлами **Apple Silicon (`arm64`) и Intel (`x86_64`)**, включая помощники для хуков и настройки.
2. Откройте DMG и перетащите **Focus Island** в «Программы», либо распакуйте ZIP и переместите приложение туда. Для обновления замените предыдущую версию.
3. Сборка подписана ad-hoc, **без нотаризации Apple**. Если macOS блокирует запуск, после попытки открытия используйте «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть».
4. В **Settings → Setup → CLI Hooks** установите хуки Claude Code, Codex или обоих агентов. Для Codex отдельно проверьте и подтвердите доверие к хукам через `/hooks` в Codex CLI, затем отправьте промпт и убедитесь, что диагностика показывает **Receiving Codex events**.

## Что нового

- **Codex вместе с Claude Code:** отдельные сессии и статусы, привязка к задачам, таймеры, история, запуск и возобновление через `codex resume`.
- **Независимая настройка агентов:** установка и удаление хуков Codex не требуют подключения Claude Code. Существующие хуки сохраняются, изменяемая конфигурация резервируется.
- **Общие отчёты:** пересекающиеся интервалы работы Claude Code и Codex не суммируются дважды; разбивка по агентам сохраняется.
- **Три языка:** English по умолчанию, Español и Русский в Settings → General → Language. Выбор применяется к интерфейсу, датам и формируемым отчётам, сохраняя исходный текст задач, промптов и ответов.
- **Версия сборки:** единый файл `VERSION` задаёт версию приложения для релизов и локальных сборок.

## Ограничения Codex preview

Codex подключается по желанию. Адаптер и интерфейс проверены синтетическими тестами; приёмочные проверки доверенных хуков в реальном Codex и жизненного цикла desktop-клиента ещё не завершены. Минимальная поддерживаемая версия Codex пока не заявлена; ранее исследовалась CLI `0.163.0-alpha.11.1`.

Разрешения подтверждаются в Codex. Промпты копируются в буфер обмена; прямая отправка отключена. Точное переключение на разговор, вопросы, шаги плана, подагенты, статистика использования, облачные и удалённые сессии не поддерживаются. После 15 минут без события сессия становится неподтверждённой и перестаёт накапливать время.

Миграция базы данных v6 создаёт снимок `before-codex-*.sqlite`. Для отключения интеграции удалите хуки Codex в Setup; не заменяйте текущую базу старой без сохранения новых данных.
