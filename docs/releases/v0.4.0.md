# Focus Island v0.4.0 — Codex and three interface languages

A native app for macOS 14 or later, with Claude Code support, a preview of Codex integration, and an interface in English, Spanish, and Russian.

## Installation and updates

1. Download `Focus.Island.dmg` or `Focus.Island.zip` below. Both contain the same universal app with native **Apple Silicon (`arm64`) and Intel (`x86_64`)** binaries, including the hook and setup helpers.
2. Open the DMG and drag **Focus Island** into Applications, or extract the ZIP and move the app there. To update, replace the previous version.
3. The build uses ad-hoc signing and is **not notarized by Apple**. If macOS blocks it, attempt to open the app, then use System Settings → Privacy & Security → Open Anyway.
4. In **Settings → Setup → CLI Hooks**, install hooks for Claude Code, Codex, or both. For Codex, separately review and trust the hooks through `/hooks` in the Codex CLI, then send a prompt and confirm that diagnostics show **Receiving Codex events**.

## What's new

- **Codex alongside Claude Code:** separate sessions and statuses, task binding, timers, history, and support for starting sessions and resuming them with `codex resume`.
- **Independent agent setup:** install and remove Codex hooks without connecting Claude Code. Existing hooks are preserved, and changed configuration is backed up.
- **Combined reports:** overlapping Claude Code and Codex work intervals are not counted twice; per-agent breakdowns remain available.
- **Three languages:** English by default, plus Spanish and Russian in Settings → General → Language. The choice applies to the interface, dates, and generated reports; task text, prompts, and replies stay as written.
- **Build version:** a shared `VERSION` file sets the app version for release and development bundles.

## Codex preview limitations

Codex is opt-in. The adapter and interface have been tested with synthetic fixtures; acceptance checks for trusted hooks in a live Codex client and the desktop client's lifecycle are still pending. No minimum supported Codex version is certified yet. The previously inspected CLI was `0.163.0-alpha.11.1`.

Approve requests in Codex. Queued prompts are copied to the clipboard; direct sending is disabled. Exact conversation targeting, questions, plan steps, subagents, usage statistics, cloud sessions, and remote sessions are not supported. After 15 minutes without an event, a session becomes unconfirmed and stops accumulating time.

Database migration v6 creates a `before-codex-*.sqlite` snapshot. To disconnect the integration, uninstall Codex hooks in Setup. Preserve newer data before replacing the current database with an older copy.
