# Focus Island v0.1.1 — Keep sessions connected

Fixes a problem where the island stopped receiving Claude Code events and showed only one session.

## Installation and updates

```bash
gh release download -R dias-zhanabayev/focus-island -p install.sh -O - | zsh
```

## Fixes

- **Claude Code bridge:** a second instance of Focus Island, such as a development build running alongside the installed app, no longer takes over the running app's socket. Previously, it recreated the socket and left it inactive when it exited, silently dropping hook events and causing sessions to disappear from the island.
- **Release packaging:** the launch check during packaging no longer touches the running app's socket.
