# Focus Island v0.3.0 — Click to open and accurate session limits

The island can open only when clicked, overload warnings count sessions belonging to the current task, and prompt previews no longer show internal tags.

## Installation and updates

1. Download `Focus.Island.dmg` below — one file for Apple Silicon and Intel.
2. Open the DMG and drag **Focus Island** into Applications. When updating, replace the previous version.
3. On first launch, right-click the app → Open.
4. Click "Connect" in the island below the notch to install the Claude Code hooks.

> [!NOTE]
> The build is signed with a local certificate and is not notarized by Apple, so macOS asks you to confirm the first launch. If "Open" does not appear, use System Settings → Privacy & Security → Open Anyway.

## What's new

- **Click to open:** turn off Settings → General → "Open island on hover" to open the island only by clicking the notch. The default behavior is unchanged.

## Fixes

- **Overload is measured within the task:** the "Nth session in this task" card appears only when the task in focus exceeds your session limit. Sessions from other tasks and unbound sessions no longer trigger the "Starting your eighth session" warning.
- **Clean prompt previews:** the "New session" pill, session titles, and task names generated from the first prompt show the actual text without internal tags such as `<system-reminder>`.
